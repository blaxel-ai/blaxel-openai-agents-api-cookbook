Blaxel Sandboxes provide isolated compute environments for AI agents.

This cookbook connects a Blaxel Sandbox to an OpenAI Agents API self-hosted session. The Codex executor runs inside the sandbox, reads workspace files, and connects outbound to OpenAI without exposing an inbound port.

Agent Drive gives independent agent sessions a durable filesystem for context and artifacts. When Agent Drive is available, this run's input and output remain on the drive after the OpenAI session and Blaxel Sandbox are deleted. Without Agent Drive access, the same task runs against disposable sandbox storage.
